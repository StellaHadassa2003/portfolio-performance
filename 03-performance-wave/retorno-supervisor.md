# Retorno do supervisor

O alerta só gera efeito se alguém responde por ele. O Wave transforma o recebimento do alerta em uma **etapa obrigatória** do fluxo semanal.

---

## Fluxo

1. O supervisor abre o totem e vê, para o seu setor e turno, o resumo da análise de cada caso com alerta, incluindo os críticos.
2. Para cada caso, informa se vai agir e de que forma (opções fechadas: vai agir, já agiu, vai observar, outra).
3. Enquanto houver casos sem retorno, os **feedbacks semanais ficam bloqueados** para esse supervisor.
4. Se quiser mais detalhe, consulta a análise completa no Wave.

## Por que bloquear

Sem bloqueio, o alerta vira mais uma notificação ignorada. O bloqueio é leve (alguns minutos por semana, respostas fechadas) e acontece quando o supervisor já está no totem por outro motivo: o feedback do time.

## Desenho de dados

- Uma tabela de retorno por caso e por supervisor, ligada ao caso pela semana e pelo colaborador.
- O retorno é **fechado na forma** (opções) e **obrigatório na existência**.
- O mesmo desenho alimenta a medição posterior das ações.

## Cuidados

- O alerta precisa de uma chave estável (semana + colaborador). Se o job rodar de novo, o retorno não pode se perder.
- Respostas são visíveis só para quem tem papel de gestão sobre o setor.
